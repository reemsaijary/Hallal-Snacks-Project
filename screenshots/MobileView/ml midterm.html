When do we use inplace=True in pandas?

You use inplace=True when you want to change the original DataFrame directly, without creating a new one.

In simple words:

It edits the table “in its place” instead of making a copy.

Example 1 — Dropping a column

Without inplace:

python
new_data = data.drop(columns=["ProductCategory"])

This creates a new table called new_data.
The original data is still the same.

With inplace:

python
data.drop(columns=["ProductCategory"], inplace=True)

Now the original data is permanently changed ✅

Use inplace=True when:
✅ You don’t need the old version
✅ You are cleaning or fixing the main dataset
✅ You want to save memory

Example 2 — Removing missing values

Without inplace:

python
data = data.dropna()

With inplace:

python
data.dropna(inplace=True)

Both lines do the same thing, just different styles.

Example 3 — Fill missing values

Without:

python
data['Age'] = data['Age'].fillna(data['Age'].mean())

With:

python
data['Age'].fillna(data['Age'].mean(), inplace=True)

When NOT to use inplace=True ❌

Don’t use it when:
❌ You still need the original data
❌ You want to compare before vs after
❌ You’re testing different methods

In those cases, create a new variable instead.

Easy rule to remember

If you say:

“I’m DONE with the old data” → use inplace=True

If you say:

“I might need the old data” → DON’T use it
